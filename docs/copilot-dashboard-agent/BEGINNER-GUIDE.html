Build your first Copilot agent

No coding. About 30 minutes. You need a work account with Copilot Studio. Menu names change often; if a button moved, look for the same word nearby.

Step 1: Get your files

  • Open this repo folder: docs/copilot-dashboard-agent
  • Download skill/file-dashboard/SKILL.md (the skill)
  • Download sample-sales.csv (good test file)
  • Download sample-bad.csv (bad test file)

Step 2: Make a folder

  • Open SharePoint and your team site
  • Click New, then Folder
  • Name it Dashboards-Inbox

Step 3: Create the agent

  • Go to copilotstudio.microsoft.com and sign in
  • Click Create, then New agent
  • Name it Dashboard Builder
  • Use the new agent experience (skills need it)

Step 4: Upload the skill

  • Open your agent and click the Build tab
  • In the left list, click Skills
  • Click Upload a skill
  • Drag in SKILL.md or click to browse
  • Wait for the green check (the file is checked for you)
  • If it shows an error, make sure the file starts with --- and has name and description

Step 5: Wake the agent on new files

  • Open the Overview tab
  • Find Triggers, click Add trigger
  • Pick When a file is created (SharePoint)
  • Choose your site and Dashboards-Inbox
  • Click Create, then Publish

Step 6: Test the skill (chat)

  • Open the test chat on the right of the agent screen
  • Paste the text of sample-sales.csv and type: Summarize this file
  • Expected: Rows 7, Units 67, Revenue 2,090, top region North (1,040)
  • Now paste sample-bad.csv
  • Expected: a warning about the text values eight and n/a, and the blank region
  • If numbers differ, the skill is wrong. Re-upload it and test again

Step 7: Test the agent (real file)

  • Upload sample-sales.csv into Dashboards-Inbox
  • In the agent, open the Activity tab
  • A new run should appear within a few minutes
  • Open it and check the same numbers as Step 6
  • Upload sample-bad.csv and check for the warnings
  • Upload an empty file. Expected: it says the file is empty

Step 8: See the dashboard

  • Download dashboard.html and double-click it
  • Click Choose file and pick sample-sales.csv
  • You see totals, two charts and a table
  • For an always-updating link, a developer hosts the page (see NO-POWERBI.md)

Test checklist

  • Skill uploaded with no error
  • Chat test passes for good and bad file
  • Trigger test starts a run
  • Dashboard page shows 7 rows
