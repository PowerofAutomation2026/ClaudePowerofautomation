Build your first Copilot agent

No coding. About 30 minutes. You need a Microsoft 365 work account with Copilot Studio.

Part 1: What you will make

  • An agent that wakes up when a file lands in a SharePoint folder
  • It reads the file and tells you the totals
  • It gives you a link to a dashboard page

Part 2: Get ready

  • Open SharePoint and go to your team site
  • Click New, then Folder, and name it Dashboards-Inbox
  • Download sample-sales.csv from this repo folder
  • Open copilotstudio.microsoft.com and sign in

Part 3: Create the agent

  • Click Create, then New agent
  • Name it Dashboard Builder
  • In Instructions, paste this:
When a new file appears in Dashboards-Inbox, read it.
Reply with: file name, number of rows, column names,
the total of each number column, and 3 short insights.
Never invent numbers. If you cannot read the file,
say what went wrong.
  • Click Create

Part 4: Make it wake up on new files

  • Open the agent, go to the Overview tab
  • Find Triggers and click Add trigger
  • Pick When a file is created (SharePoint)
  • Choose your site and the Dashboards-Inbox folder
  • Click Create, then Publish

Part 5: Test it

  • Upload sample-sales.csv to Dashboards-Inbox
  • Open the agent's Activity tab and look for a new run
  • The answer should say: 7 rows, Units 67, Revenue 2,090
  • If the numbers are different, do not trust the agent. Tell it to re-read the file

Part 6: See the dashboard

  • Download dashboard.html and double-click it
  • Click Choose file and pick sample-sales.csv
  • You will see totals, two charts and a table
  • Later, a developer can host the page so the link refreshes by itself

If something goes wrong

  • No run appears: check the folder name and that you clicked Publish
  • Agent cannot read the file: save the file as CSV, not Excel
  • Numbers look wrong: check for text in number columns

Menu names change often. If a button has moved, search the Copilot Studio help for the same name.
