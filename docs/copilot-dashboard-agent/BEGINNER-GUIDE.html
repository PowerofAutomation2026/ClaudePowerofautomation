Build your first Copilot agent

No coding. About 30 minutes. Menu names change often: if a button has moved, look for the same word nearby.

The 3 parts:
  1. Where to upload your files
  2. Create the Copilot Studio agent
  3. Test it

PART 1: Where to upload your files

1.1 Download the 3 files from this repo folder

FileWhat it isGoes to
skill/file-dashboard/SKILL.mdThe skill (the agent's instructions)Copilot Studio, Part 2
sample-sales.csvGood test fileSharePoint folder, Part 3
sample-bad.csvBad test fileSharePoint folder, Part 3

1.2 Make the SharePoint folder (the "inbox")

  1. Open SharePoint and go to your team site
  2. Click Documents
  3. Click New, then Folder
  4. Name it Dashboards-Inbox and click Create

Do not upload the test files yet. You will do that in Part 3.

PART 2: Create the Copilot Studio agent

2.1 Make the agent

  1. Go to copilotstudio.microsoft.com and sign in
  2. Click Create, then New agent
  3. Name: Dashboard Builder
  4. Use the new agent experience (skills need it)
  5. Click Create

2.2 Upload the skill

  1. Open your agent and click the Build tab
  2. In the left list, click Skills
  3. Click Upload a skill
  4. Drag in SKILL.md, or click to browse
  5. Wait for the green check
Success: file-dashboard appears in the Skills list.

Error? Make sure the file starts with --- and has a name and a description.

2.3 Make the agent wake up on new files

  1. Open the Overview tab
  2. Find Triggers and click Add trigger
  3. Pick When a file is created (SharePoint)
  4. Choose your site and the Dashboards-Inbox folder
  5. Click Create

2.4 Publish

  1. Click Publish (top right)
  2. Wait for "Published"

PART 3: Test it

3.1 Test the skill in chat (no file upload)

  1. Open the test chat panel on the right
  2. Open sample-sales.csv in Notepad, copy all the text
  3. Paste it into the chat and type: Summarize this file
Success: 7 rows. Units 67. Revenue 2,090. Top region North (1,040).
  1. Do the same with sample-bad.csv
Success: warnings about eight, n/a and the blank region. No invented totals.

3.2 Test the whole agent (real file)

  1. Go to the Dashboards-Inbox folder in SharePoint
  2. Click Upload, then Files, and pick sample-sales.csv
  3. Go back to your agent and open the Activity tab
  4. Wait a few minutes and refresh
  5. Open the new run
Success: a new run appears, with the same numbers as 3.1.
  1. Upload sample-bad.csv the same way and check for warnings
  2. Upload an empty .csv file
Success: the agent says the file is empty.

3.3 See the dashboard page

  1. Download dashboard.html and double-click it
  2. Click Choose file and pick sample-sales.csv
Success: 7 rows, totals, two charts and a table.
Final checklist
  • Folder Dashboards-Inbox exists
  • Skill shows in the Skills list
  • Trigger added and agent published
  • Chat test passes (good and bad file)
  • Activity tab shows a run for the uploaded file
If something goes wrong
  • No run appears: check the folder name, then that you published
  • Wrong numbers: re-upload the skill and test again
  • Agent cannot read the file: save it as .csv
