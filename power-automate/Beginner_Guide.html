Copy a SharePoint Folder Structure
A step-by-step guide for complete beginners

This guide installs a ready-made automation ("flow") that copies every folder from one SharePoint library to another site, then marks each original folder Copied = Yes. You do not need to write any code. Allow about 15 minutes.

About the pictures: the screenshots are simplified drawings, not photos of your screen. Microsoft changes its screens often, so words and positions may differ slightly. Look for the button names in bold and the orange highlights.

Before you start: checklist

  • A work or school Microsoft 365 account that can use Power Automate.
  • You can open both SharePoint sites and have Edit or Owner rights on both (the flow creates folders and adds a column).
  • Your environment must have Dataverse (the "Solutions" menu must exist). Most work accounts do. If you cannot see "Solutions", ask your IT admin.
Tip: try it first with two test sites or test libraries, not live data.

  2. Open the source library: there is a new column Copied; every folder shows Yes. If you do not see the column, click + Add column → Show/hide columns and tick Copied.

If something goes wrong

I cannot see "Solutions"Your environment has no Dataverse. Ask IT for one, or tell me and I will give you a non-solution version.
Import failsTake a screenshot of the error and send it to me; I will fix the package.
Run shows FailedClick the failed run, then the red step. Common causes: a typo in the site URL (do not add a trailing /), a wrong library name, or you lack Edit rights on one of the sites. Fix the input and Run again; nothing gets duplicated.
"Access denied" or 403You need Edit/Owner on both sites. Ask the site owner.
How do I undo?Delete the new folders in the destination library. The flow never deletes anything. The Copied column can be removed in library settings.
